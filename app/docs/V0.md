# DropShare — V0

## Goal

Build and ship a small Android application in Kotlin that allows two devices on the same local network to share files directly.

## V0 Scope

### User flow

1. Device A opens DropShare.
2. Device A selects a file.
3. Device A starts sharing.
4. Device B connects to Device A over the local network.
5. Device B downloads the file.
6. Both devices show basic transfer status.

## Technology

- Kotlin
- Android
- Jetpack Compose
- Kotlin Coroutines
- Local-network HTTP
- Android Storage Access Framework

## V0 Architecture

```text
Device A
┌──────────────────────┐
│ Compose UI           │
│                      │
│ Select File          │
│       ↓              │
│ Local HTTP Server    │
└──────────┬───────────┘
           │ Wi-Fi / LAN
           │
           ▼
┌──────────────────────┐
│ Device B             │
│                      │
│ Connect              │
│       ↓              │
│ Download File        │
└──────────────────────┘
```

## Deliberately Out of Scope

- User accounts
- Cloud storage
- Database
- Authentication
- Internet file sharing
- Encryption beyond what is provided by the chosen transport
- Multi-file queues
- Background transfers
- Fancy animations
- Complex architecture

## Engineering Principle

Keep V0 small.

The goal is not to build a production-grade file-sharing platform today. The goal is to understand the complete path:

**Android UI → file system → network → HTTP server → second device → file system → shipped APK.**

Future versions can add discovery, authentication, encryption, resumable transfers, and better peer-to-peer protocols.
